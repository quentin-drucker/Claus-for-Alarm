there Godot must decompress these maps to uncompressed on load (no memory saving, extra load time) — enabling ETC2/ASTC
(for_mobile) is the next step if mobile matters (adds the second format to the .pck). Resolution reduction (process/size_limit
512) was not applied: S3TC alone met the goal; 1024^2 maps on ~40 px models would allow it (~-12 MB more) after a visual check.
