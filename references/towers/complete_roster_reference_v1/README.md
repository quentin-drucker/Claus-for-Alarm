## Visual direction and modeling use

- Shared chunky toy forms, bold dark outlines, soft shading and saturated navy/red/teal/brown/gold palette.
- Elf towers retain the approved friendly face family, with role-specific costumes, body shapes and equipment.
- These are base-tier concepts, not upgrade-path designs.
- Generated orthographic-style concept art is not a dimensionally calibrated blueprint. Establish proportions in the model and reconcile small projection differences, especially handheld props and foot orientation.
- Scale is matched within each paired sheet as a visual guide; sheets do not establish physical scale between different towers.
- New designs are reference proposals; inclusion does not imply separate user approval of each design or a change to the game's implementation.
- Hockey Slapper and Snowboard Trickster remain planned. Winter Games Lodge and Track Gritter are DEFERRED beyond the hackathon: existing concept sheets are retained only for a possible expansion, not authorization for creation or submission.
- Labels are in filenames and this index so the artwork stays clear.

PROMPTS.md contains the exact prompts used for all nine new sheets.
