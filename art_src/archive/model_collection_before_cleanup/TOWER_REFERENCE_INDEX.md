# Tower reference folders

The eight additional Tripo exports are listed in [Tripo model files](TRIPO_MODELS.md), with descriptive FBX names and their original texture folders preserved.

Front and side views stay together in each primary PNG, including the Cannon. The approved Rookie sheet also includes the back.

This collection was moved from the Desktop into `art_src/models/`. Model files and texture dependencies retain their original relative paths. The parent `art_src/.gdignore` keeps these source materials out of Godot's runtime imports.

Model1's [final AccuRIG-rigged FBX](Model1/accurig/model1_elf_FINAL_RIGGED_MODEL.fbx) is saved in `Model1/accurig/`, alongside its exported JSON, expression frame map, and textures. Earlier model versions remain in Model1.
